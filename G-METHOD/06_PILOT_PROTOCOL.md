# UMEA Pilot Protocol

**Status:** NOT RUN. This document is a test protocol, not evidence that a pilot has occurred.

## Objective
Test whether the matrix produces repeatable, evidence-grounded decisions for a real organization without inventing requirements or over-scoring missing evidence.

## Minimum pilot steps
1. Select one real case with permission to use the data.
2. Record organization context and confidentiality classification.
3. Freeze the registry version used for the test.
4. Map applicable functions, level, and documentation tier; log every unresolved relationship.
5. Gather evidence for C/O/E/R/K/S/M fields.
6. Have a second reviewer independently assess a sample of records.
7. Compare reviewer agreement, missing-evidence rate, time to complete, and decision usefulness.
8. Record false positives, false negatives, confusing definitions, and rules that require revision.
9. Obtain owner approval before promoting proposed rules to canonical rules.

## Pilot outputs
- Case scope and consent/authorization
- Anonymized evidence index where appropriate
- Completed matrix snapshot
- Reviewer disagreement log
- Findings and limitations
- Change requests
- Go/no-go decision with approver and date

## Stop conditions
Stop or restrict the pilot if confidential data is exposed, evidence provenance is unclear, the framework is being used outside its approved scope, or results are represented as certification/assurance without authorization.
